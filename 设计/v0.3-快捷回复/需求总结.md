# XPremium-Helper v0.3 快捷回复

## 背景

X 的回复编辑器适合直接输入，但重复性的感谢、互动和礼貌回应仍需要反复输入。当前扩展已经支持 Enter 发送回复，本版本在不改变发送边界的前提下，增加草稿辅助。

## 目标

- 在当前回复框旁提供常用回复和模型生成入口。
- 只把用户选择的内容插入草稿，不自动发送。
- 允许用户配置 OpenAI Chat Completions 兼容接口。
- 将 API Key 和自定义模板保存在本机，不保存模型候选和聊天历史。

## 范围

包含回复框识别、当前帖文上下文读取、内置模板、自定义模板、接口配置、域名权限申请、模型候选和草稿插入。

不包含自动回复、批量回复、自动点赞、自动关注、私信快捷回复、整页上下文发送和远程服务端代理。

## 关键决策

- 浮层贴近当前回复编辑器显示。
- 聚焦回复框不会自动请求模型，必须点击“生成回复”。
- 首版使用 OpenAI Chat Completions 格式。
- API 权限按用户填写的接口域名单独申请；只允许 HTTPS 和 localhost 开发地址。
- 选择结果只插入 X 草稿，保留 Enter 发送。
- 内置模板长期保存；自定义模板可编辑、删除和分类；模型候选只留当前页面内存。
- 模型只接收当前留言、作者公开昵称/账号、语言和语气。
- 本版本沿用现有 XPremium-Helper 面板风格，不使用额外背景图。

## 验收口径

隔离 Chromium 和 Edge 使用本地模拟接口验证；真实 X 只验证编辑器识别和草稿插入，不发送真实回复。模型接口地址、API Key 和留言内容不写入测试日志。
