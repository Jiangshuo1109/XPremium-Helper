# 安全问题 / Security

当前维护最新预览版本；历史预览包不承诺安全修复回补。项目尚无独立安全审计或响应时限承诺。

如果问题可能导致错误账号操作、身份混淆、隐私泄漏或不经用户点击执行，请不要公开发布真实账号、聊天、令牌或可直接利用的细节。

优先使用仓库 **Security → Report a vulnerability**（若已启用）。若该入口不可用，请先通过 [@jiangza9](https://x.com/jiangza9) 请求私下沟通渠道，不要在公开回复中放漏洞细节。如果无法取得私下渠道，可开一个只说明“需要安全联络”的 Issue。

报告请包括版本、浏览器版本、最小虚构样例、实际与预期行为、影响范围及临时缓解方法。普通布局或兼容性问题可通过 Issue 模板反馈。

## English

Only the latest preview is actively maintained. No independent security audit or guaranteed response time is claimed.

Use **Security → Report a vulnerability** if enabled. Otherwise, ask [@jiangza9](https://x.com/jiangza9) for a private contact channel without posting exploit details publicly. A public issue requesting security contact is an alternative when private contact is unavailable.

Include the extension/browser version, a minimal fictional reproduction, expected and actual behavior, impact, and possible mitigation. Never include real conversations, account lists, cookies, or credentials. Identity confusion, unintended actions, and privacy leaks should be reported privately.
