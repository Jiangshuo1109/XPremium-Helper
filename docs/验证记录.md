## 已知限制

1. 这是严格原生控件模式，只有页面同时存在该账号明确的原生关注控件时才能显示。不能满足「所有陌生人头像直接出现按钮」。
2. 原生资料卡收起会移除控件，快捷按钮随之隐藏；未实现后台预读或自动展开资料卡。
3. 新版 `/i/chat` 的发言者头像结构已确认并补适配，关系读取与原生操作未完成；会话列表及顶部身份关联仍未完成。
4. 中文和英文是当前识别语言，其他语言不推测。
5. 消息头像选择器已确认，但资料卡及关系控件选择器未完成实站确认。必须通过实机验收后才能声称支持 X 当前版本。
6. 请求成功只依据 X 可见控件状态；超过观察窗口的服务端失败或回滚尚需实机测试。
7. 追加的「未确认互关显示取关」不把缺少标记当成服务端关系证明；真实账号的取关确认与速度限制 CD 仍需实站验收。
